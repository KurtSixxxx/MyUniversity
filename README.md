*   📘 **14 moduli**, dalle classi ai grafi: analogie, disegni della memoria, codice C++ commentato (senza STL, come vuole il corso) e le trappole tipiche d'esame.
*   ✅ **165 quiz** con simulazione cronometrata (30 domande, 60 minuti, soglia 18), proprio come la prova a crocette.
*   💻 **169 esercizi** da scrivere e compilare con `g++ -Wall -Wextra`, con il confronto automatico tra il tuo output e quello della soluzione.
*   🎤 **71 domande d'orale** come flashcard, con risposta modello e ripetizione distanziata.
*   📱 **Sul telefono** (Android e iPhone) si installa dal browser e funziona anche offline: quiz e orale nei tempi morti.

Gratis, open source, fatto da uno studente per gli studenti. Se ti è utile, lascia una ⭐ alla repository!

## Struttura della Repository
La repository è organizzata in modo da facilitare la ricerca del materiale:
*   **Anno_01/**: Materiale del primo anno (Analisi, Algebra, Programmazione, ecc.)
*   **Anno_02/**: Materiale del secondo anno (Algoritmi, Sistemi Operativi, ecc.)
*   **Anno_03/**: Materiale del terzo anno e risorse per la laurea.

Ogni cartella d'anno è ulteriormente suddivisa in **Semestre_01** e **Semestre_02**.

## Come contribuire
Se desideri integrare i tuoi appunti:
1. Effettua un fork della repository.
2. Aggiungi il materiale nella cartella corrispondente.
3. Invia una Pull Request.

## Note tecniche su Video e Git LFS
I file video delle lezioni non sono inclusi per via dei limiti di dimensione di GitHub. 
Questa repository utilizza **Git LFS** per la gestione di file PDF e archivi pesanti. 

**Nota per il download:** In caso di errori durante il download dei file di grandi dimensioni, potrebbe essere dovuto al superamento del limite mensile di banda di GitHub LFS. Si consiglia di riprovare il mese successivo o di consultare i link ai Drive esterni nella sezione [Link e Fonti](./Risorse%20Universitarie/Link%20e%20Fonti).
