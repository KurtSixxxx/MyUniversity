## 1. COME SI CREA UNA CLASSE IN PROCESSING (JAVA)

Una classe è un **modello** (uno stampino) per creare oggetti.

```java
class NomeClasse {

  // Attributi (caratteristiche)
  tipo nomeAttributo;
  tipo nomeAttributo2;

  // Costruttore (serve per creare oggetti)
  NomeClasse(tipo parametro1, tipo parametro2) {
    this.nomeAttributo = parametro1;
    this.nomeAttributo2 = parametro2;
  }

  // Metodi (azioni che l'oggetto può fare)
  tipoDiRitorno nomeMetodo() {
    // codice
    return qualcosa; // se il tipoDiRitorno non è void
  }
}
```

### Esempio concreto:

```java
class Cane {
  String nome;
  int eta;

  // Costruttore
  Cane(String nome, int eta) {
    this.nome = nome;
    this.eta = eta;
  }

  // Metodo
  void abbaia() {
    println(nome + " dice: Bau!");
  }
}
```

## 2. COME SI CREA UN OGGETTO IN PROCESSING

Un oggetto è una **istanza concreta** di una classe (come un cane vero creato dallo stampino `Cane`).

```java
// Sintassi: NomeClasse nomeOggetto = new NomeClasse(parametri);
Cane fido = new Cane("Fido", 3);
Cane spot = new Cane("Spot", 5);
```

### Come si usano gli oggetti:

```java
fido.abbaia();  // stampa "Fido dice: Bau!"
spot.abbaia();  // stampa "Spot dice: Bau!"

println(fido.eta);  // stampa 3
println(spot.nome); // stampa "Spot"
```

## 3. COS'È UN ARRAYLIST (E LA SUA SINTASSI)

Un **ArrayList** è un contenitore che può crescere e restringersi dinamicamente (a differenza degli array normali che hanno dimensione fissa).

### Dichiarazione:

```java
ArrayList<Tipo> nomeVariabile;
```

Dove `Tipo` è la classe degli oggetti che conterrà.

### Creazione (inizializzazione):

```java
nomeVariabile = new ArrayList<Tipo>();
```

Oppure tutto in una riga:

```java
ArrayList<Tipo> nomeVariabile = new ArrayList<Tipo>();
```

### Esempio concreto:

```java
ArrayList<Cane> cani;           // dichiarazione
cani = new ArrayList<Cane>();   // creazione

// Oppure in una riga:
ArrayList<Cane> cani = new ArrayList<Cane>();
```

**Nota sul nome:** in Processing, `ArrayList` vuole la **A maiuscola** e la **L maiuscola**.  
Mai scrivere `arraylist` o `Arraylist` – darebbe errore!

## 4. METODI PRINCIPALI DI UN ARRAYLIST

| Metodo              | Cosa fa                           | Esempio                   |
| ------------------- | --------------------------------- | ------------------------- |
| `add(oggetto)`      | Aggiunge un oggetto alla fine     | `cani.add(fido);`         |
| `get(indice)`       | Restituisce l'oggetto all'indice  | `Cane c = cani.get(0);`   |
| `size()`            | Restituisce il numero di elementi | `int n = cani.size();`    |
| `remove(indice)`    | Rimuove l'elemento all'indice     | `cani.remove(0);`         |
| `clear()`           | Rimuove tutti gli elementi        | `cani.clear();`           |
| `contains(oggetto)` | Controlla se l'oggetto è presente | `if(cani.contains(fido))` |
| `isEmpty()`         | Controlla se è vuoto              | `if(cani.isEmpty())`      |

### Esempio pratico:

```java
ArrayList<Cane> cani = new ArrayList<Cane>();

cani.add(new Cane("Fido", 3));  // aggiungo un cane
cani.add(new Cane("Spot", 5));  // aggiungo un altro cane

println(cani.size());  // stampa 2

Cane primo = cani.get(0);  // prendo il primo cane
primo.abbaia();            // "Fido dice: Bau!"

cani.remove(0);  // rimuovo il primo cane
println(cani.size());  // stampa 1
```

## 5. COS'È E COME SI USA UN CICLO FOR-EACH

Il **for-each** è un modo compatto per scorrere **tutti** gli elementi di una collezione (ArrayList, array, ecc.).

### Sintassi:

```java
for(Tipo nomeVariabileTemporanea : nomeCollezione) {
  // codice da eseguire per ogni elemento
}
```

### Esempio con ArrayList:

```java
ArrayList<Cane> cani = new ArrayList<Cane>();
cani.add(new Cane("Fido", 3));
cani.add(new Cane("Spot", 5));
cani.add(new Cane("Rex", 2));

// For-each: "per ogni cane nella lista cani"
for(Cane c : cani) {
  c.abbaia();  // chiama abbaia() su ogni cane
}
```

### A cosa corrisponde?

Il for-each è equivalente a:

```java
for(int i = 0; i < cani.size(); i++) {
  Cane c = cani.get(i);
  c.abbaia();
}
```

### Quando NON usare for-each:

- Se hai bisogno dell'indice (es. `i`)
- Se devi modificare la lista mentre la scorri (es. rimuovere elementi)

In quei casi si usa il for normale con indice.

## RIASSUNTO PER L'ESAME

```java
// 1. CREARE UNA CLASSE
class Cane {
  String nome;
  Cane(String nome) { this.nome = nome; }
  void abbaia() { println(nome + " Bau!"); }
}

// 2. CREARE OGGETTI
Cane fido = new Cane("Fido");

// 3. ARRAYLIST
ArrayList<Cane> cani = new ArrayList<Cane>();
cani.add(fido);
cani.add(new Cane("Spot"));

// 4. METODI ARRAYLIST
cani.size();        // numero elementi
cani.get(0);        // primo elemento
cani.remove(0);     // rimuove primo

// 5. FOR-EACH
for(Cane c : cani) {
  c.abbaia();
}
```
